# 🍺 BAR HUB - Duplicator System

A mobile-friendly web interface for the BAR HUB item duplication system.

## Features

✅ **Item Inventory** - View all items with stats (damage, rarity, crit chance, durability)  
✅ **Deep Copy System** - Perfectly clone items without reference issues  
✅ **Unique IDs** - Every duplicate gets a unique identifier  
✅ **Mobile Optimized** - Beautiful interface that works on phones  
✅ **Real-time Stats** - Track total items and duplicates  

## How to Use

1. **Open the app** - Open `index.html` in your browser
2. **Select an item** - Click on any item to highlight it
3. **Duplicate** - Click "📋 Duplicate Selected" button
4. **View results** - Your duplicate appears with `[COPY]` tag and unique ID
5. **Manage** - Use Refresh or Clear All buttons as needed
